It stops the expensive accidents and leaves normal work alone

A guard that blocks normal work gets switched off. So each rule is either a hard stop, a question for you, or out of the way.

Blocked

  • rm -rf on ~, / or the whole project
  • Force-push to main, master or production
  • DROP, TRUNCATE, DELETE with no WHERE
  • Committing a real API key
  • Editing .env, private keys, .git or the guards themselves
  • Fork bombs and disk wipes

Asks you first

  • prisma migrate reset, supabase db reset
  • terraform destroy
  • git reset --hard
  • Reading .env into the conversation
  • Writing a real API key into a file with Claude's edit tool

Allowed

  • rm -rf node_modules .next dist
  • git push to a feature branch
  • --force-with-lease on your own branch
  • prisma migrate dev
  • grep "DROP TABLE" schema.sql

Each rule can be set to block, ask or off. A log-only dry-run mode shows what would have been stopped before you switch anything on.

Before you trust it

What it is

Plain Python 3.8+, standard library only. No network calls, no telemetry, no account. You can read every line in one sitting before you install it.

The installer backs up your settings.json first, and install.py --uninstall puts it back.

What it is not

It reads command text, so it is a seatbelt, not a vault. An unusual command can get past it. Keep backups, and keep production credentials out of your project folder.

Tested on Linux with Python 3.11 to 3.13 and live inside Claude Code 2.1.304. The test suite passes on one Windows PC with Python 3.12.6. It has not yet been run live inside Claude Code on Windows, and macOS is untested.

Questions

Will it slow Claude down?

Each check is a small local script that runs before a tool call. In normal use you won't notice it.

Will it block my normal work?

Everyday commands like rm -rf node_modules, pushes to a feature branch and prisma migrate dev are allowed. If a rule gets in your way, set it to ask or off in config.json.

What do I need?

Claude Code and Python 3.8 or newer. On Windows, Git for Windows, which Claude Code uses to run hooks.

How do I install it?

Unzip, open a terminal in your project and run python path/to/install.py. Add --preview first to see what it will change. It takes about two minutes.
